# Scope 縮小決議（2026-10-03）

使用者於規劃審核時決定縮小範圍。**本文件優先於 `2026-10-03-yellow-line-parking-design.md`**；
設計書中與本文件衝突或超出本文件的部分視為失效。

## 縮小後的範圍

> 只標示「假日可以黃線停車」的路段，也只判斷這一件事。

1. 地圖標出官方 PDF 的 99 筆假日開放黃線路段
2. 取得使用者 GPS 位置，顯示附近路段並依距離排序
3. 判斷「**現在是否處於可停狀態**」= 今天算假日 AND 當下落在該路段的開放時段內

## 從原設計刪除的項目

| 刪除 | 原因 |
|---|---|
| 四態判斷（allowed / temp_only / forbidden / unknown） | 簡化為**兩態**：可停 / 不可停。「非開放時段僅可臨停 3 分鐘」降為說明文字，不是狀態 |
| `lineType` 欄位 | 資料來源全為黃線，無紅線資料，欄位無用 |
| `restrictionType` 欄位與「夜間開放」預留 | 不做夜間，不預留 |
| 夜間開放黃線路段表的調查 | 超出範圍 |
| 側向 offset 繪製（同路兩側平移線條） | 改用文字標示方向／側別，不做幾何平移 |

## 保留的硬性安全要求

- 幾何無法確認的路段**不得**顯示為可停；頁面須誠實標示已收錄筆數（N / 99）
- 官方免責原文「本表僅供參考，實際開放黃線假日停車路段仍以現場標誌標示範圍為準」須常駐頁面
- 補班日（需上班的週六）不算假日 → 判定為不可停（保守側）
